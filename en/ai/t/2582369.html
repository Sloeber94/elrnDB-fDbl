B10 ENGINE DOES NOT START / UNDER NO CIRCUMSTANCES

Applies to: all engines; all production periods

The engine does not start. When the key is turned, the instruments light up, the starter motor turns to the Avv position, but the engine will not start.

The MIL warning light should come on with the ignition on and go out once the engine has started; if there is a fault in the panel the CODE system failure will be present.

Applies to: all engines; all production periods

PRELIMINARY CHECKS

All OK

Problems met

Operation

Turn the key to the ON position and check that the I.E and CODE lights come on for the start-up test

The I.E light should come on for about 4 seconds and then switch off, while the CODE light should come on for about 1 second and the switch off.

Check

  • that the inertia switch has not cut in
  • the state of the spark plugs and leads;
  • that there are no obstructions in the catalytic converter;
  • that there is no water in the fuel

PRELIMINARY CHECKS

All OK

Problems met

Operation

First check that there is petrol in the tank (since the engine operates on petrol and on methane it always starts up in petrol mode);

Check whether the inertia switch has been operated

Check, in order:

  • Condition of the petrol pump fuse;
  • That the methane engine management control unit relays are correctly fitted
  • The state of the spark plugs and leads;
  • The condition of the air intake circuit;
  • Possible obstruction in the catalyzer
  • That there is no water, other fluids or dirt in the fuel filter;
