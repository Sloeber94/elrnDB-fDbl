The CO percentage measured is very low, with a corresponding NOx percentage higher than the recommended figure.

Applies to: all engines; all production periods

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect diagnostic equipment (Examiner or other instruments) to the diagnostic socket.

Check that there are no faults in the engine management control unit

Continue to Step 2

'Supply system' error detected

See table Z50 MIXTURE STRENGTH ERROR

'Misfire' error detected

See table Z53 MISFIRE ERROR

'Catalytic converter' error detected

See table Z55 CATALYZER ERROR

'Upstream lambda sensor' error detected

See table Z56 UPSTREAM LAMBDA SENSOR SIGNAL ERROR

'Downstream lambda sensor' error detected

See table Z58 DOWNSTREAM LAMBDA SENSOR SIGNAL ERROR

Another error detected in the control unit

Continue following the instructions for the diagnostic equipment

Lack of dialogue with the control unit

Restore the connection between the engine management control unit and the diagnostic connector See E5030

2

ACTIVE DIAGNOSIS WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Using the diagnostic equipment (Examiner or other instruments) carry out active diagnosis of the injectors

Continue to Step 3

Connections faulty

Restore the connection of the injectors and the solenoid with the control unit See E5030

Faulty injector

Replace injector Op. 1056B70 injector (one) - r + r with fuel manifold pipe removed - includes seal replacemnt

3

CHECKING LAMBDA SENSOR

All OK

Problems met

Operation

Check that the Lambda sensor is working properly

Continue to Step 4

Upper lambda sensor defective

Replace the upper Lambda sensor Op. 1080B94 front lambda probe with catalitic converter r r

Lower lambda sensor defective

Replace the lower Lambda sensor Op. 1080B95 rear lambda probe with catalitic converter r r

4

CHECKING AIR CIRCUIT

All OK

Problems met

Operation

Check the condition of the air supply circuit

Continue to Step 5

Circuit component damaged

Replace the component involved

5

CHECKING BLOW-BY CIRCUIT

All OK

Problems met

Operation

Check the condition of the blow-by gas intake circuit, in particular, check that there are no obstructions in the separator or the pipes

Continue to Step 6

Circuit faulty

Restore the operation of the system

Fault in the separator

Replace the separator

CHECKING FUEL PRESSURE

All OK

Problems met

Operation

Continue to Step 7

Pressure not correct
