I05 DIPPED HEADLAMPS NOT WORKING

Applies to: all engines; all production periods

When the steering column switch unit ring nut is operated with the ignition ON, the dipped headlamps do not work

Applies to: all engines; all production periods

Results of the tests

1

CHECK INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition of individual bulbs and light units.

Continue to Step 2

Left bulb damaged

Replace the bulb Op. 5540B22 l/h or r/h headlamp/light cluster bulb (one) - r+r

Right bulb damaged

Replace the bulb Op. 5540B22 l/h or r/h headlamp/light cluster bulb (one) - r+r

Light unit faulty

Repair or change the front light unit Op. 5540B79 right front light cluster with turn signal and foglamp r r

2

DIPPED HEADLAMPS ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • right and left dipped headlamp fuses;
  • dipped headlamp maintenance relay;
  • connections between steering column switch unit-Body Computer and junction unit;
  • connections between junction unit and bulbs
  • bulb earth See E2011

Continue to Step 3

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore connections See E2011

3

STEERING COLUMN SWITCH UNIT CHECK

All OK

Problems met

Operation

Check that the stalk unit is working properly; in particular check the side lights switch Characteristic of working principle 5550A stalk unit

Continue to Step 4

Steering column switch unit not working properly

Replace the steering column switch unit Op. 5550A12 complete stalk unit - r+r for versions with air bag

4

CHECK ON BODY COMPUTER

All OK

Problems met

Operation

Check that the Body Computer is supplied properly

Check that when an earth signal from stalk unit to Body is activated, an earth signal is emitted from the Body to drive the dipped beam headlamps relay: See E2011

Continue to Step 5

Body Computer supply incorrect

Restore the correct supply See E2011

Body Computer faulty

Replace the Body Computer Op. 5505A32 body computer - r r

5

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
