J20 REARSCREEN AND DOOR MIRROR DEFROSTING NOT WORKING

Applies to: all engines; all production periods

With the ignition on, when the heated rear window button on the control panel is pressed, neither the rear window nor the door mirrors warm up properly

Applies to: all engines; all production periods

Results of the tests

1

FUSE CHECK

All OK

Problems met

Operation

Check, in order:

  • Fuse in engine compartment unit
  • Condition of connecting cable between fuse and heated rear window relay in dashboard unit See E3030

Continue to Step 2

Component defective

Replace the component (if a fuse is involved, search for the cause of the problem)

Connections not correct

Restore connections

2

HEATED REAR WINDSCREEN SWITCH CHECK

All OK

Problems met

Operation

Check the operation of the heated rear window switch on the control panel Also check the connection to the Body Computer

Continue to Step 3

Faulty switch

Replace the control panel Op. 5505A24 w/l and service switch mount - r+r

Connection not correct

Restore connections

3

CHECK ON HEATED REAR WINDOW RELAY

All OK

Problems met

Operation

Check the operation of the heated rear window relay and the condition of the connecting cables

Continue to Step 4

Relay faulty

Replace the relay

Connection not correct

Restore connections

4

CHECK ON BODY COMPUTER

All OK

Problems met

Operation

Check that the Body Computer sends the signal to operate the heated rear window relay

Continue to Step 5

No signal

Replace the Body Computer Op. 5505A32 body computer - r r

5

CHECK ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • Fuses for heated rear window and door mirrors
  • Connecting cables between dashboard unit and rear window
  • Connecting cables between dashboard unit and door mirrors
  • Earth cable for rear window and door mirrors

Continue to Step 6

Component defective

Replace the component (if a fuse is involved, search for the cause of the problem)

Connections not correct

Restore connections

Fuse unit faulty

Replace the fuse box Op. 5505A10 electrical junction unit - r+r

6

CHECK ON DEMISTING HEATING ELEMENTS

All OK

Problems met

Operation

Check the demisting heating elements on the rear window and door mirrors

Continue to Step 7

Rear window heating element broken

Replace the rearscreen Op. 7035B24 tinted window of one load compartment rear door flap r r including cleaning of housing on flap

Door mirror heating element broken

Restore the continuity See E3030

7

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
