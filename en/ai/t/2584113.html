0010M20 120,000km service coupon, emission control versions

Applies to: all engines; all production periods

Position the vehicle on a lift.

Check the tyre tread is not irregularly worn.

Some types of tyre are fitted with wear gauges; these tyres should be replaced as soon as these gauges are visible on the tread.

Do not swap tyres across.

Check the tyre inflation pressure is correct. Also check the spare wheel.

The tyre pressures must be checked when they are cold.

Check that the lighting system is operating correctly: headlamps, turn signals, hazard lights, luggage compartment light, passenger compartment light, oddment compartment light and instrument panel warning lights.

Check the windscreen wiper system is operating correctly and adjust the sprays if necessary.

Check the front and rear wiper blades are correctly positioned and not worn.

Remove the front wheels

Op. 4450B12 FRONT WHEELS (TWO) - R.R.

, then visually inspect the condition of the front disc brake pads and ensure they are not worn.

Check the condition and wear of the rear drum brake linings

Op. 3320B34 REAR BRAKE DRUMS - R.R.

Carry out a visual check of:

body exterior

underbody protection

rigid and flexible pipe sections (exhaust, fuel system, brakes)

rubber components (gaiters, sleeves, bushes etc.)

Check that the bonnet and boot are clean and that the linkage is clean and lubricated.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Heater

Visually inspect the condition of the alternator drive belt.

Visually inspect the condition of the power assisted steering pump drive belt.

Applies to: engines: 1.2 8v; all production periods; only with equipment: Climate control system

Visually inspect the condition of the alternator drive belt.

Visually inspect the condition of the compressor drive belt.

Visually inspect the condition of the power assisted steering pump drive belt.

Applies to: engines: 1.4 8v, 1.6 16v, 1.3 JTD 16V, 1.9 JTD 8V; all production periods

Proceed with replacing the single engine components drive belt.

Op. 1092G10 SINGLE ENGINE BELT - R.R.

Applies to: engines: 1.9 JTD 8V, 1.9 DIESEL; all production periods

Proceed with checking the tappet clearance and adjust, if necessary

Op. 1036H10 VALVE TAPPETS - CHECK AND ADJUST CLEARANCE

Applies to: engines: 1.2 8v, 1.4 8v; all production periods

Proceed with checking the tappet clearance and adjust, if necessary

Op. 1036H10 VALVE TAPPETS - CHECK AND ADJUST CLEARANCE

Applies to: all engines; all production periods

Check and, if necessary, adjust handbrake lever

Op. 3380A04 HANDBRAKE - ADJUST TRAVEL

Applies to: engines: 1.3 JTD 16V, 1.9 JTD 8V, 1.9 DIESEL; all production periods

Check the exhaust gas emissions/fumes

Op. 1080A20 EXHAUST FUMES - CHECK WITH OPACIMETER

Applies to: engines: 1.3 JTD 16V, 1.9 DIESEL; all production periods

Replace the fuel filter

Op. 1044B10 FUEL FILTER ASSEMBLY - R + R OR REPLACE

Applies to: engines: 1.9 JTD 8V; all production periods

Replace the fuel filter

Op. 1044B20 FUEL FILTER FILTERING ELEMENT - REPLACE

Applies to: engines: 1.2 8v, 1.4 8v, 1.6 16v; all production periods

Change the air cleaner cartridge

Op. 1048A14 AIR CLEANER FILTERING ELEMENT - REPLACE.

Applies to: engines: 1.3 JTD 16V, 1.9 JTD 8V, 1.9 DIESEL; all production periods

Change the air cleaner cartridge

Op. 1048A14 AIR CLEANER FILTERING ELEMENT - REPLACE.

Applies to: all engines; all production periods

Check and, if necessary, top up the engine coolant level.

Op. 0010T21 COOLANT - CHECK DENSITY AND TOP UP IF NECESSARY

Check and, if necessary, top up the brake fluid level.

Op. 0010T64 BRAKE AND/OR CLUTCH FLUID CHECK LEVEL AND TOP UP AS NECESSARY

Check and, if necessary, top up the windscreen washer fluid level

Op. 5050A14 RESERVOIR PLUG (IN ENGINE COMPARTMENT) OR WINDSCREEN WASHER FLUID LEVEL SENSOR - CHECK AND TOP UP IF NECESSARY

Check and, if necessary, top up the battery fluid level.

Check and, if necessary, top up the power assisted steering fluid level

Op. 0010T71 POWER STEERING FLUID CHECK LEVEL AND TOP UP IF NECESSARY

Applies to: engines: 1.2 8v, 1.4 8v, 1.6 16v; all production periods

Replace the spark plugs.

Op. 5510D10 SPARK PLUGS - R+R

Applies to: all engines; all production periods

Connect the EXAMINER or other diagnostic equipment to the diagnostic socket (select the control unit in question), then check the plausibility of all the parameters and, if necessary, carry out the active diagnosis.

Change the engine oil and filter

Op. 0010T12 ENGINE OIL AND FILTER - REPLACE

For the 1.9 D version, the engine oil and filter should be replaced every 10,000 km.For the Multijet versions, the engine oil and filter should be replaced every 30,000 km or 24 months (*).(*) The actual interval for changing the oil and replacing the engine oil filter depends on the vehicle usage conditions and is signalled by the warning light or message, if present, in the instrument panel.

Replace the brake fluid

Op. 0010T62 BRAKE AND/OR CLUTCH FLUID - CHANGE FLUID INVOLVES WASHING PIPES AND BLEEDING AIR

The brake fluid filter should be changed every 24 months.

Replace the pollen filter

Op. 5010B09 PURIFYING (POLLEN) FILTER FILTER ELEMENT - REPLACE

The pollen filter should be replaced every 24 months.

Remove the vehicle from the lift.
