I20 FOG LIGHTS NOT WORKING

Applies to: all engines; all production periods

When the front fog lamps switch is operated with the side lights on, the front fog lamps do not work.

The front fog lamps are not enabled with the main beam headlamps on

Applies to: all engines; all production periods

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) to the diagnostic socket

Check that there are no errors in the Body Computer

Continue to Step 2

Fog lights relay short-circuiting to battery

Restore the correct connection See E2030

2

CHECK INDIVIDUAL LIGHTS

All OK

Problems met

Operation

Check the condition/insulation of the individual bulbs and lamps

Continue to Step 3

Left bulb damaged

Replace the bulb Op. 5540B22 l/h or r/h headlamp/light cluster bulb (one) - r+r

Right bulb damaged

Replace the bulb Op. 5540B22 l/h or r/h headlamp/light cluster bulb (one) - r+r

Lamps faulty

Repair or change the front light unit Op. 5540B79 right front light cluster with turn signal and foglamp r r

3

CHECK FOG LAMP ELECTRIC CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • front fog lamp fuse;
  • fog lights relay;
  • engine compartment control unit supply;
  • connections between Body Computer and engine compartment control unit;
  • connections between engine compartment control unit and bulbs;
  • connections between Body Computer and fog lights switch;
  • bulb earth : See E2030

Continue to Step 4

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore connections See E2030

4

CHECK ON BODY COMPUTER

All OK

Problems met

Operation

Check that the Body Computer is working properly, in particular the front fog lamps control function

Continue to Step 5

Device not working

Replace the Body Computer Op. 5505A32 body computer - r r

5

CHECK FOG LAMP SWITCH

All OK

Problems met

Operation

Check the operation of the fog lights switch See E2030

Continue to Step 6

Fog lights switch faulty

Replace the control panel Op. 5505A24 w/l and service switch mount - r+r

6

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

Fault persists

Search for the fault starting from another symptom'
