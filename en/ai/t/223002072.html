Applies to: engines: 1.2 8v, 1.6 16v, 1.3 JTD 16V, 1.9 JTD 8V, 1.9 DIESEL; production: da 12/03; only with equipment: Right hand drive

Description

The front door electric windows are operated by switches in the middle of the facia.

The operation is manual: the glass only goes up/down when the button is pressed. Both windows can only be operated when the ignition is ON.

One some versions, if the button for operating the driver's electric window is pressed for more than half a second, the automatic operation is activated: the window stops when it reaches the end of travel position or if the button is pressed again.

Operation is enabled for two minutes after turning the ignition from ON to OFF, only with the doors properly closed.

The circuit for the electric windows is protected by two special fuses, one for the driver's side and one for the passenger side and is controlled by a specific relay located in the under-facia junction unit.
