Basic operation

Once the error has been cancelled, if the check shows that the error has not reappeared then the test is over.

Disconnect the driver side air bag connector and activate the line closure resistor, with resistance at 2 Ohm.

Delete the error and check that it has disappeared using a testing device such as Examiner.

Reconnect the driver side bag connector

Disconnect the connector from the clock spring and activate the relevant line closure resistor

Delete the error and check that it has disappeared using a testing device such as Examiner.

Reconnect the clock spring connector

Check the condition of the wiring: there should be no interruptions or DC.

If there are no faults, the control unit is faulty.
