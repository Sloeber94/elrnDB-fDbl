Applies to: all engines; all production periods

It is not possible to order a single lock barrel or to order barrels using a single part code. When ordering barrels, observe the special procedure set out in operationOp. 5580 SPECIAL ACCESSORIES.

Applies to: engines: 1.2 8v, 1.6 16v, 1.3 JTD 16V, 1.9 JTD 8V, 1.9 DIESEL; all production periods; only with equipment: Doblò trim level
