PRELIMINARY CHECKS

All OK

Problems met

Operation

Preliminarily carry out a visual inspect to locate the component or area which is leaking.

Check that there is no engine oil in the coolant.

Check that there is no water or emulsion in the engine oil.

If the visual inspection is not sufficient, wash the engine, dry it, start it and run it slowly until it comes up to temperature; to identify the leak, carry out a leak test on the system Op. 0510C30 cooling system - tightness test
