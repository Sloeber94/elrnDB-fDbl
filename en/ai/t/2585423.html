Applies to: all engines; all production periods

AF (ALTERNATIVE FREQUENCY):

Radio device function which makes it possible, whilst receiving an RDS programme broadcast by several transmitters on different frequencies, to automatically switch to the frequency with the best reception.

Applies to: all engines; all production periods

BALANCE

Radio device function which makes it possible to adjust the sound distribution between the left and right side speakers

Applies to: all engines; all production periods

BASS

Radio device function which makes it possible to adjust the acoustics (LOW TONES)

Applies to: all engines; all production periods

EON

Radio device function which makes it possible to receive information on traffic conditions from radio channels not currently tuned into, temporarily interrupting the station being listened to.

Applies to: all engines; all production periods

FADER

Radio device function which makes it possible to adjust the distribution of the sound between the speakers.

Applies to: all engines; all production periods

FM

Long wave radio transmission frequency between 87.5 and 108 MHz.

Applies to: all engines; all production periods

GPS (GLOBAL POSITIONING SYSTEM)

Satellite positioning system which is designed to provide any user with the possibility of determining their position on the earth's surface.

Applies to: all engines; all production periods

GSM

Communication standard for mobile equipment (GSM = Global System for Mobile Communication) currently used in about 90 counties enjoying optimum coverage.

Applies to: all engines; all production periods

LOUDNESS

Radio device function which makes it possible to improve the sound by increasing the low tones.

Applies to: all engines; all production periods

LW

Long wave radio transmission frequency between 153 and 279 KHz.

Applies to: all engines; all production periods

MW

Long wave radio transmission frequency between 531 and 1602 KHz.

Applies to: all engines; all production periods

NIT

Telematic Info Connector

Applies to: all engines; all production periods

POI (Point of interest)

This consists of keying in an information sequence in order to select a particular POI (in relation to which other information can be obtained)

Applies to: all engines; all production periods

PTY

Radio device function which makes it possible, with the RADIO mode activated, to select the type of programme, e.g.: NEWS (news and current affairs), AFFAIRS (politics and events) etc. for the radio stations which provide this type of information.

Applies to: all engines; all production periods

RDS (RADIO DATA SYSTEM)

Radio data system designed for radio transmission in the range 87.5 to 108.0 MHz

Applies to: all engines; all production periods

RG (Route Guidance)

Route guidance

Applies to: all engines; all production periods

TA

Radio device function which makes it possible, if set, to receive traffic news broadcasts irrespective of the current radio operating mode.

The reproduction of a CD is interrupted and the volume is automatically increased.

Applies to: all engines; all production periods

TFT (THIN FILM TRANSISTOR)

Technology used for the construction of liquid crystal screens.

Applies to: all engines; all production periods

TP (TRAFFIC PROGRAMME)

RDS transmitter with traffic news.

Applies to: all engines; all production periods

TREBLE

Radio device function which makes it possible to adjust the acoustics (HIGH TONES)
