Applies to: all engines; all production periods

With the ignition key in the ON position, when the buttons in the control panel are operated the front electric windows do not work.

Applies to: all engines; all production periods

Results of the tests

1

SWITCH SUPPLY CHECK

All OK

Problems met

Operation

Check, in order:

  • Engine compartment control unit fuse
  • Switch supply See E3050

Continue to Step 2

Component defective

Replace the component (if a fuse is involved, search for the cause of the problem)

Connections not correct

Restore connections

2

RELAY CHECK

All OK

Problems met

Operation

Check, in order:

  • Relay operation
  • Relay supply cables
  • Cables connected to the Body Computer See E3050

Continue to Step 3

Component defective

Replace the component (if a fuse is involved, search for the cause of the problem)

Connections not correct

Restore connections

3

CHECK ON BODY COMPUTER

All OK

Problems met

Operation

Check that the Body Computer sends the signal to the relay.

Continue to Step 4

No signal

Replace the Body Computer Op. 5505A32 body computer - r r

4

FUSE CHECK

All OK

Problems met

Operation

Check, in order:

  • Fuses in dashboard fuse box
  • Dashboard fuse box
  • Supply cable between fuses and switches See E3050

Continue to Step 5

Component defective

Replace the component (if a fuse is involved, search for the cause of the problem)

Fuse control box defective

Replace the fuse box Op. 5505A10 electrical junction unit - r+r

Connections not correct

Restore connections

5

SWITCH EARTH CHECK

All OK

Problems met

Operation

Check the condition of the earth lead for the switches in the control panel See E3050

Continue to Step 6

Connections not correct

Restore connections

Problems met

Operation

Continue to Step 7

Connections not correct

Restore connections

All OK

Problems met

Operation

Switches not working
