Results of the tests

1

'INSTRUMENT PANEL' CONTROL UNITS TEST

All OK

Problems met

Operation

Using the EXAMINER diagnostic equipment, carry out the 'AUTOTEST' active diagnosis.

The brake fluid level warning light should come on

Continue to Step 2

Warning light bulb does not come on

Replace the instrument panel Op. 5560B11 analogue control panel - r+r or replace

2

'BODY COMPUTER' CONTROL UNITS TEST

All OK

Problems met

Operation

Using the EXAMINER diagnostic equipment, carry out the active diagnosis of the 'brake fluid warning light (CAN)'. The warning light should come on for several seconds

Continue to Step 3

The warning light does not come on for several seconds

Check that the connection between the Body Computer and the Instrument Panel is correct (see Wiring Diagram E4010); if it is OK, replace the Body Computer Op. 5505A32 body computer - r r

3

CHECK SWITCH

All OK

Problems met

Operation

Check, in order:

  • The operation of the switch
  • Connection between the switch and the Body Computer See E4010

Continue to Step 4

Faulty switch

Replace switch Op. 3330A30 brake fluid level indicator device - check device on reservoir - includes plug replacement and level top up if necessary

Conenctions not working properly

Restore connections See E4010

4
