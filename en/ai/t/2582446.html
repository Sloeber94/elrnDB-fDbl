Applies to: all engines; all production periods

The engine management control unit warning light remains on. The CODE warning light comes on and goes out.

The CODE warning light going out means that the dialogue between the two control units has gone well. The engine management control unit warning light remaining on permanently means there is an error in the system

Applies to: all engines; all production periods
